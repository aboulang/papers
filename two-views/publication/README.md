# Publication package — review draft

This folder prepares the clean digital edition of **New Developments in Mathematics, Computing, the Sciences, and New Views of Computation** for a deliberate public release.

## Historical provenance

- **Original work:** Albert Boulanger, BBN Laboratories; presented at the 1986 Computers and Mathematics Conference.
- **Controlling source:** the scanned conference-paper PDF in this repository.
- **Transcription method:** the earlier Scribe source and bibliography repaired OCR errors; obvious typographical errors were corrected conservatively; wording and historical terminology were otherwise preserved.

## Contents

- `CITATION.cff` — machine-readable citation metadata including the author's ORCID iD.
- `zenodo-record-metadata.json` — metadata for a manual Zenodo record and DOI reservation.
- The clean Markdown, DOCX, and PDF remain one directory above as the source release material.

## Release gate

Do **not** publish this package until the following have been explicitly completed:

1. **Completed:** rights holder has confirmed the right to republish this clean digital edition under CC BY-ND 4.0.
2. Reserve a Zenodo DOI, add it to the final PDF, public HTML page, and citation records, and publish the Zenodo record.
3. Copy the final searchable PDF to the public-site publication directory.
4. Merge the corresponding public-site review pull request.

This package deliberately does not claim a DOI or license before those decisions.
